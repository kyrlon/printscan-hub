Brother: where to enter this
  1. Open the printer's Device settings (link next to the printer above) and log in. The default password is on a label on the printer, marked “Pwd”.
  2. Scan → Scan to FTP/SFTP/Network/SharePoint: set Profile 1 to FTP and click Submit.
  3. Scan → Scan to FTP/SFTP/Network/SharePoint Profile → Profile 1: enter the values above. Name it “PrintScan Hub”.
  4. On the printer: Scan → to FTP/SFTP → PrintScan Hub → Start.

Other brands call this “Scan to FTP”, “Scan to Folder”, or “Address book → FTP destination”. The values are the same.
