Drivers

Most printers from the last ~10 years need nothing here: add them with the built-in everywhere driver. The hub also already includes about 17,000 drivers for older models. Use this section only when your printer isn't covered.

Type the make and model. Shows the drivers already installed and any open-source driver packages from Debian you can install with one click.

Vendor .deb packages (Brother, Epson, Canon, Kyocera…), .ppd/.ppd.gz files, or a .sh install script. Use the Linux “Debian / Ubuntu / .deb” download from the vendor site.

Advanced: install Debian packages by name

For when you already know the package name. Otherwise use Find a driver above, which lists matching packages with an Install button.

Everything installed here is remembered in the drivers/printer/ folder and re-installed automatically when the container is rebuilt or updated. You can also drop files into that folder and click Re-install all.
